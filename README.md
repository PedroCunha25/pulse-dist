# PULSE — distribuição

Repositório público só com a fonte SideStore/AltStore e as Releases (IPA) do PULSE, uma app iOS pessoal e não comercial para a WHOOP 4.0. O código-fonte é privado.

## Instalar no SideStore
1. SideStore → Sources → ＋ → cola: `https://raw.githubusercontent.com/PedroCunha25/pulse-dist/main/altstore-source.json`
2. Instala o PULSE a partir da fonte. As atualizações aparecem automaticamente.

A assinatura com Apple ID gratuito expira a cada 7 dias; o SideStore renova-a — mantém-no instalado.
